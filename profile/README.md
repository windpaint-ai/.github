# Windpaint

Generate media. Manage every asset.

[Windpaint](https://windpaint.ai) is a developer API for open-weight image and video models, asset
storage and variants, and multi-step workflows. It is in early access.

- Website: [windpaint.ai](https://windpaint.ai)
- Docs: [docs.windpaint.ai](https://docs.windpaint.ai)
- Models: [windpaint.ai/models](https://windpaint.ai/models)
- MCP server: `https://mcp.windpaint.ai/mcp` ([setup](https://docs.windpaint.ai/agents/mcp))
- Agent skills for Claude Code, Codex and Cursor: [windpaint-ai/skills](https://github.com/windpaint-ai/skills)
- CLI: [windpaint-ai/cli](https://github.com/windpaint-ai/cli) (no release yet)
- Early access: [app.windpaint.ai/register](https://app.windpaint.ai/register)
